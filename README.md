# 📊 E-Commerce Sales Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **E-Commerce Sales Dashboard** created using Microsoft Power BI.

The dashboard provides a clear overview of sales performance, profitability, quantity sold, payment methods, customer performance, state-wise sales, monthly profit trends, and sub-category profitability.

The purpose of this project is to transform raw e-commerce data into meaningful business insights that can help management understand sales trends and make data-driven decisions.

---

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance
- Track total sales, profit, quantity, and average order value
- Identify the best-performing product categories
- Analyze sales across different states
- Understand customer-wise sales performance
- Analyze payment method preferences
- Monitor monthly profit trends
- Identify the most profitable sub-categories
- Provide an interactive dashboard for business decision-making

## 📈 Dashboard Features

### 1. Sales & Profit KPIs
Provides a quick overview of total sales, profit, quantity, and average order value.

### 2. Quarterly Analysis
Interactive quarter filters allow users to analyze performance across:

- Qtr 1
- Qtr 2
- Qtr 3
- Qtr 4

### 3. State-wise Sales Analysis
The dashboard compares sales across different states, including:

- Maharashtra
- Madhya Pradesh
- Uttar Pradesh
- Delhi

### 4. Category Analysis
The category chart shows the quantity contribution of:

- Clothing
- Electronics
- Furniture

### 5. Payment Mode Analysis
The dashboard analyzes quantity by payment method:

- COD
- UPI
- Debit Card
- Credit Card
- EMI

### 6. Monthly Profit Analysis
Monthly profit trends help identify profitable and loss-making months.

### 7. Customer Analysis
The dashboard compares sales performance across customers.

### 8. Sub-Category Profitability
Profit is analyzed across sub-categories such as:

- Printers
- Bookcases
- Saree
- Accessories
- Tables

---

## 🔍 Key Insights

Some important insights from the dashboard include:

- **Clothing** contributes the largest share of quantity at approximately **63%**.
- **COD** is the most-used payment method, contributing approximately **43.74%** of quantity.
- **Maharashtra** has the highest sales among the displayed states.
- **Printers** generate the highest profit among the displayed sub-categories.
- Monthly profit varies significantly, with some months showing negative profit.
- Customer-level analysis highlights differences in sales contribution between customers.
